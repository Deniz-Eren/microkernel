# ADR_0006 — Separate SYS_SIGPROCMASK Kernel ABI and Enforce libc.a Safety Gate

```{adr} Separate SYS_SIGPROCMASK kernel ABI and enforce libc.a safety gate
:id: ADR_0006
:status: accepted

## Context

`SWR_SIG_0003` and `SWR_SIG_0004` require POSIX.1-2024 `<signal.h>`, `-EINVAL`
for `SIGKILL`/`SIGSTOP`, mask reload across `SYS_SIGRETURN`, and
async-signal-safety. Earlier, `<sys/signal.h>` leaked `<sys/microkernel.h>`, had
no `SYS_SIGPROCMASK` syscall, and left `sig_frame_t.pad` unused.

## Decision

- Separate the low-level kernel ABI (`libc/include/sys/signal.h`, `struct
  __k_sigaction`, `SYS_SIGPROCMASK = 27`) from the public POSIX `<signal.h>`
  header and out-of-line wrappers in `libc/src/signal.c`.
- Use the 8-byte `pad` slot in `sig_frame_t` as `saved_mask` to keep the 16-byte
  frame layout. Save and restore `blocked_signals`, and store `sa_mask` and
  `sa_flags` in `pcb_t`.
- Add CTest `posix.async_signal_safe` (`tests/posix/test_async_signal_safe.py`)
  using `llvm-objdump -dr` on `libc.a`. Parse calls and `R_X86_64_*` relocations
  to block heap, stdio, or `exit` callees.

## Rejected alternatives

- Passing `struct sigaction` directly as the kernel ABI struct (couples kernel
  layout to future `siginfo_t` or `sa_sigaction` extensions).
- Auditing async-signal-safety only by manual source review.

## Consequences

- `<signal.h>` compiles standalone under C17 with `_POSIX_C_SOURCE=202405L` and
  `_XOPEN_SOURCE=800` without leaking `SYS_*`.
- `sigtest` verifies `SIGKILL`/`SIGSTOP` `EINVAL`, `sigprocmask` deferral, and
  mask restoration in QEMU, while CTest guards `libc.a` on every build.
```
