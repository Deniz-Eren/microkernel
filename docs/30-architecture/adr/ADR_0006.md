# ADR_0006 — Isolated SYS_SIGPROCMASK Kernel ABI and libc.a Safety Check

```{adr} Isolated SYS_SIGPROCMASK kernel ABI and libc.a safety check
:id: ADR_0006
:status: accepted

## Context

For `SWR_SIG_0003` and `SWR_SIG_0004`, the system must give POSIX.1-2024
`<signal.h>`, `-EINVAL` for `SIGKILL` and `SIGSTOP`, mask load across
`SYS_SIGRETURN`, and async-signal-safety. Before this decision, `<sys/signal.h>`
included `<sys/microkernel.h>`, had no `SYS_SIGPROCMASK` syscall, and did not
use `sig_frame_t.pad`.

## Decision

- The architecture isolates the kernel ABI (`libc/include/sys/signal.h`, `struct
  __k_sigaction`, `SYS_SIGPROCMASK = 27`) from the public POSIX `<signal.h>`
  header and wrappers in `libc/src/signal.c`.
- `sig_frame_t` uses the 8-byte `pad` slot as `saved_mask` to keep the 16-byte
  frame layout. The kernel keeps and loads `blocked_signals` and keeps `sa_mask`
  and `sa_flags` in `pcb_t`.
- CTest `posix.async_signal_safe` (`tests/posix/test_async_signal_safe.py`)
  operates `llvm-objdump -dr` on `libc.a`. It parses calls and `R_X86_64_*`
  relocations to reject heap, stdio, or `exit` targets.

## Rejected alternatives

- `struct sigaction` as the kernel ABI struct, which connects kernel layout to
  future `siginfo_t` or `sa_sigaction` fields.
- Manual source inspection only for async-signal-safety.

## Results

- `<signal.h>` compiles standalone in C17 with `_POSIX_C_SOURCE=202405L` and
  `_XOPEN_SOURCE=800` without `SYS_*` macros.
- `sigtest` does tests of `SIGKILL` and `SIGSTOP` `EINVAL`, `sigprocmask`
  deferral, and mask load in QEMU. CTest does the `libc.a` safety check on each
  build.
```
