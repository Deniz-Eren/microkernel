# ADR_0023 — Select on Multi-Server ppoll and Kernel Memory Release

```{adr} Select on multi-server ppoll and kernel memory release
:id: ADR_0023
:status: accepted

`<sys/select.h>` (`select`, `pselect`, `fd_set`, `FD_*`) operates as a Ring 3
layer on multi-server `ppoll()`. Ring 0 releases zombie process and thread
allocations, and `SYS_SYS_STATS` and server stats IPC calls make sure that QEMU
tests have no memory leaks.
```

## Context

For `SWR_DOCS_0004`, the system must give `<sys/select.h>` (`select`, `pselect`)
across all Ring 3 descriptor servers. It must also do quantitative checks of PMM
frame, descriptor, and server slot counts during high-load tests. Kernel
inspection during `TSK_0020` showed that `sys_proc_wait()` released user page
tables but kept `pcb_t`, `conn_table`, and thread blocks on `kheap`. Long-lived
processes also did not release zombie thread stacks on exit.

## Decision

- `libc/include/sys/select.h` (`ICD_IPC_0014`) gives `FD_SETSIZE = 64`, `struct
  timeval`, `fd_set`, `FD_CLR`, `FD_ISSET`, `FD_SET`, `FD_ZERO`, `select`, and
  `pselect` without `<sys/microkernel.h>`. `libc/src/select.c` (`COMP_IPC_0014`)
  operates the two functions on multi-server `ppoll()` with
  `__libc_cancel_point()` calls and `POLLNVAL` to `EBADF` conversion.
- `proc_reap_zombie_threads()` releases zombie thread user stacks, kernel
  stacks, FPU buffers, and `tcb_t` entries. `proc_user_stack_alloc()` uses
  unmapped stack slots again, and `proc_reap_zombie()` releases `pcb_t`,
  `conn_table`, and threads during `sys_proc_wait()`.
- The system adds `SYS_SYS_STATS` (`52`, `SysStats()` in `<sys/vm.h>`) with
  `PIPE_OP_STATS`, `VFS_OP_STATS`, and `SOCK_OP_STATS` IPC calls.
  `tests/stresstest/test_stress.c` (`VER_DOCS_0005`) uses them to make sure that
  PMM and server slot counts stay equal before and after high-load tests.

## Rejected alternatives

- A kernel `SYS_SELECT` syscall, which duplicates Ring 3 descriptor state in
  Ring 0.
- Memory checks based only on no crashes as an alternative to accurate frame and
  server slot counts.

## Results

- `select()` and `pselect()` share multi-server poll and signal-mask logic with
  `ppoll()` and satisfy header, symbol, and cancellation checks.
- Long-lived processes and `fork`/`execvp`/`pthread_create` high-load tests
  operate with no PMM frame or server slot growth.
