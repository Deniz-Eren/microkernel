# ADR_0011 — COW fork, bootfs execve, Kernel FD Table, and Ring 3 pipeserv

```{adr} COW fork, bootfs execve, kernel FD table, and Ring 3 pipeserv
:id: ADR_0011
:status: accepted

## Context

`SWR_PROC_0004` and `SWR_IPC_0004` require POSIX.1-2024 Base `fork`, `execve`,
`pipe2`, `dup3`, `fcntl`, and `ppoll` with atomic `O_CLOEXEC` and signal mask
rules. Putting pipe buffers and poll queues in Ring 0 violates `ADR_0003`.

## Decision

- Add syscalls `42` through `47`: `SYS_PROC_FORK` (full-address-space
  `vmm_clone_user_cow` with `FS.base` and FPU inheritance), `SYS_PROC_EXECVE`
  (bootfs ELF reload with `argv`/`envp`, `O_CLOEXEC` cleanup, and signal reset),
  `SYS_PROC_GETPID`, `SYS_PROC_GETPPID`, `SYS_FD_OP`, and `SYS_SIGPENDING`.
- Store only compact per-process descriptor metadata (`struct __k_fd_entry`) in
  `pcb_t.fds[]`. Send `PULSE_CODE_FD_CLOSE` pulses on `execve` `O_CLOEXEC`
  cleanup and process exit.
- Run pipe ring buffers, reader/writer refcounts, deferred blocking I/O, and
  timed `ppoll` queues in Ring 3 `servers/pipeserv` (`/dev/pipe`) over IPC.
- Keep `fork`, `execve`, `pipe2`, `dup3`, `fcntl`, `close`, `poll`, `ppoll`, and
  `sigpending` in `libc` async-signal-safe with zero heap allocation.

## Rejected alternatives

- Putting pipe ring buffers and poll wait queues directly inside Ring 0.
- Implementing `O_CLOEXEC` as a non-atomic `fcntl` call after `pipe` or `dup2`.

## Consequences

- `forkpipetest` and `exechelper` verify COW `fork`, `execve` `argv`/`envp`,
  atomic `O_CLOEXEC`, Ring 3 pipe I/O, `POLLHUP`, and `ppoll` `sigmask` `EINTR`
  in headless QEMU.
- `SWR_PROC_0004` and `SWR_IPC_0004` are active and checked by `posix.headers`
  and `posix.async_signal_safe`.
```
