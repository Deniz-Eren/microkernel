# ADR_0017 — Option-Gated POSIX SHM, MAP_SHARED, and ML/MLR mlock

```{adr} Option-gated POSIX SHM, MAP_SHARED, and ML/MLR mlock
:id: ADR_0017
:status: accepted

## Context

For `SWR_MEM_0005`, the system must give `shm_open`, `shm_unlink` (`SHM`),
`mlockall`, `munlockall` (`ML`), and `mlock`, `munlock` (`MLR`) behind
`_POSIX_*` option macros. Before this decision, `mmap` operated only on private
anonymous pages, and `vmm_clone_user_cow` set all writable pages to
copy-on-write on `fork`.

## Decision

- `libc/include/sys/_posix_opts.h` keeps active option macros
  (`_POSIX_SHARED_MEMORY_OBJECTS`, `_POSIX_MEMLOCK`, `_POSIX_MEMLOCK_RANGE` =
  `202405L`). `<unistd.h>` and `<sys/mman.h>` include this internal header
  without `<unistd.h>` symbols in `<sys/mman.h>`.
- `kernel/include/kernel/vmm.h` reserves PTE software bits `VMM_SHARED` (bit 10)
  and `VMM_LOCKED` (bit 11). `fork()` keeps `VMM_SHARED` pages shared, and
  `mprotect` keeps the two bits. `fork()` and `execve()` set `VMM_LOCKED` and
  `mlock_flags` to 0 to obey POSIX.1-2024.
- `kernel/core/shm.c` (`COMP_MEM_0005`) adds `SYS_SHM_OP` (`49`), `SYS_SHM_MAP`
  (`50`), and `FD_KIND_SHM` (`4`). Named SHM objects use PMM-refcounted frames,
  set `FD_CLOEXEC` on `shm_open`, operate with `ftruncate` and `fstat`, and obey
  W^X and `O_RDONLY` write rules.
- `kernel/core/vmm.c` adds `SYS_VM_MLOCK` (`51`), which does checks of mapped
  page ranges (`ENOMEM` on unmapped pages) and `MCL_CURRENT` and `MCL_FUTURE`
  flags (`EINVAL` on incorrect flags).
- `tests/shmtest/test_shm.c` (`VER_MEM_0004`) does tests of `MAP_SHARED`,
  `MAP_PRIVATE` private pages, `shm_unlink`, `mlock`, and `mlockall`.

## Rejected alternatives

- Page copies in Ring 3 `vfsserv` through IPC for `shm_open`, which prevents
  shared-frame `MAP_SHARED` memory.
- Inclusion of `<unistd.h>` in `<sys/mman.h>`, which does not obey XSH 2.2
  header namespace rules.

## Results

- All `MEM` domain requirements (`SYS_MEM_0001`, `SWR_MEM_0001` to
  `SWR_MEM_0006`) are active with tests.
- `posix.symbol_diff` shows active option groups `ML, MLR, SHM` with no ungated
  option symbols.
```
