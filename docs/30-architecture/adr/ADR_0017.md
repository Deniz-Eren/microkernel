# ADR_0017 — Option-Gated POSIX SHM, MAP_SHARED, and ML/MLR Memory Locking

```{adr} Option-gated POSIX SHM, MAP_SHARED, and ML/MLR memory locking
:id: ADR_0017
:status: accepted

## Context

`SWR_MEM_0005` requires `shm_open`, `shm_unlink` (`SHM`), `mlockall`,
`munlockall` (`ML`), and `mlock`, `munlock` (`MLR`) behind `_POSIX_*` option
macros. Previously, `mmap` supported only private anonymous mappings and
`vmm_clone_user_cow` turned all writable pages into copy-on-write on `fork`.

## Decision

- Place active option macros (`_POSIX_SHARED_MEMORY_OBJECTS`, `_POSIX_MEMLOCK`,
  `_POSIX_MEMLOCK_RANGE` = `202405L`) in `libc/include/sys/_posix_opts.h`.
  Include this internal header from `<unistd.h>` and `<sys/mman.h>` without
  leaking `<unistd.h>` declarations into `<sys/mman.h>`.
- Reserve PTE software bits `VMM_SHARED` (bit 10) and `VMM_LOCKED` (bit 11) in
  `kernel/include/kernel/vmm.h`. Keep `VMM_SHARED` pages shared across `fork()`
  and preserve both bits in `mprotect`. Clear `VMM_LOCKED` and `mlock_flags` on
  `fork()` and `execve()` per POSIX.1-2024.
- Implement `kernel/core/shm.c` (`COMP_MEM_0005`) with `SYS_SHM_OP` (`49`),
  `SYS_SHM_MAP` (`50`), and `FD_KIND_SHM` (`4`). Back named SHM objects with
  PMM-refcounted frames, set mandatory `FD_CLOEXEC` on `shm_open`, support
  `ftruncate` and `fstat`, and enforce W^X and `O_RDONLY` write rejection.
- Implement `SYS_VM_MLOCK` (`51`) in `kernel/core/vmm.c` validating mapped page
  ranges (`ENOMEM` on unmapped pages) and `MCL_CURRENT`/`MCL_FUTURE` flags
  (`EINVAL` on invalid flags).
- Verify cross-process `MAP_SHARED`, `MAP_PRIVATE` isolation, `shm_unlink`,
  `mlock`, and `mlockall` in `tests/shmtest/test_shm.c` (`VER_MEM_0004`).

## Rejected alternatives

- Backing `shm_open` in Ring 3 `vfsserv` by copying pages over IPC (breaks true
  zero-copy cross-process `MAP_SHARED` memory sharing).
- Including `<unistd.h>` directly inside `<sys/mman.h>` (violates XSH 2.2 header
  namespace hygiene).

## Consequences

- `MEM` domain requirements (`SYS_MEM_0001`, `SWR_MEM_0001`–`0006`) are 100%
  active and verified.
- Gate 2 `posix.symbol_diff` reports active option groups `ML, MLR, SHM` with
  zero ungated option leaks.
```
