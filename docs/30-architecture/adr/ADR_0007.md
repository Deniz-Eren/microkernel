# ADR_0007 — Dynamic PMM Refcounts, VMM_COW Faults, and Milestone 5 ABI

```{adr} Dynamic PMM refcounts, VMM_COW faults, and Milestone 5 ABI
:id: ADR_0007
:status: accepted

## Context

For Milestone 5 (`SWR_MEM_0004`, `SWR_PROC_0007`), the system must give
`ProcCreate`, `VMMap`, `VMUnmap`, `VMCloneCow`, and child exit-code collection
for POSIX `<sys/mman.h>` and `<sys/wait.h>`. Copy-on-write frames must keep
frame refcounts safely and process Ring 3 `#PF` page faults without large kernel
`.bss` arrays or W^X errors.

## Decision

- `pmm_init()` dynamically allocates a `uint16_t` refcount table for all frames
  through `pmm_alloc_contiguous()` (~128 KiB on 256 MiB RAM). `pmm_free_frame()`
  uses refcounts with `pmm_frame_inc()` and `pmm_frame_refcount()`.
- The VMM reserves x86-64 software PTE bit 9 as `VMM_COW`.
  `vmm_resolve_cow_to()` processes COW page faults from `idt.c` (`#PF`) and
  `copy_user_pml4()`. It sets sole-owner pages writable without a new frame and
  releases user PML4 trees through `vmm_destroy_user_pml4()`.
- The kernel adds `SYS_PROC_WAIT = 28` and `SYS_VM_PROTECT = 29` with
  `SYS_PROC_CREATE` and `SYS_VM_*`. `libc` adds `<sys/proc.h>`, `<sys/vm.h>`,
  `<sys/mman.h>`, and `<sys/wait.h>`, and rejects `PROT_WRITE | PROT_EXEC` with
  `-EACCES`.

## Rejected alternatives

- A static 2 MiB `uint16_t` refcount array in kernel `.bss`.
- Full page duplication during `VMCloneCow` as an alternative to `#PF` page
  faults.

## Results

- `proctest` and `procchild` do tests of `ProcCreate`, `waitpid` (`WNOHANG` and
  exit status 42), `mmap`, `mprotect`, `msync`, `munmap`, W^X errors, and Ring 3
  COW page faults in headless QEMU.
```
