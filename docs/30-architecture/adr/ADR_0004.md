# ADR_0004 — Seven Microkernel Traceability Domains

```{adr} Seven microkernel traceability domains
:id: ADR_0004
:status: accepted

## Context

`ADR_0001` initialized Sphinx-Needs with a sample `POWER` domain. Those sample
items did not match `microkernel`, and kernel tests with `SYS_POWER_0001`
markers gave incorrect traceability.

## Decision

The project removes the `POWER` sample files and configures seven operating
system domains in `.docs-traceability-setup.yml`: `BOOT`, `MEM`, `PROC`, `IPC`,
`SIG`, `LIBC`, and `DOCS`. All layers from business goals to verification
markers connect across the kernel, `libc`, servers, tests, and tools.

## Rejected alternatives

- `POWER` items with `obsolete` status and sample files kept in the repository.
- One large `KERNEL` domain for all operating system subsystems.

## Results

- Each active requirement, architecture item, interface, component, and test
  marker matches a `microkernel` subsystem.
- Domain boundaries match POSIX.1-2024 compatibility work.
```
