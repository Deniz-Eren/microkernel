# ADR_0004 — Organize Traceability Into Seven Microkernel Domains

```{adr} Organize traceability into seven microkernel domains
:id: ADR_0004
:status: accepted

## Context

`ADR_0001` initialized Sphinx-Needs with a default `POWER` placeholder domain.
Those sample items did not describe `microkernel`, and tagging kernel tests
against `SYS_POWER_0001` produced misleading traceability.

## Decision

Remove the `POWER` placeholder files and configure seven real operating system
domains in `.docs-traceability-setup.yml`: `BOOT`, `MEM`, `PROC`, `IPC`, `SIG`,
`LIBC`, and `DOCS`. Populate all layers from business goals down to verification
tags across the kernel, `libc`, servers, tests, and tooling.

## Rejected alternatives

- Retiring `POWER` items as `obsolete` and keeping placeholder files in the
  repository.
- Grouping every operating system subsystem into one monolithic `KERNEL` domain.

## Consequences

- Every active requirement, architecture element, interface, component, and test
  tag matches a real `microkernel` subsystem.
- Domain boundaries map cleanly onto ongoing POSIX.1-2024 compatibility work.
```
