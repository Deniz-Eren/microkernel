# ADR_0018 — Ring 3 Serial TTY Server, Termios, and Multi-Server ppoll

```{adr} Ring 3 serial TTY server, termios, and multi-server ppoll
:id: ADR_0018
:status: accepted

## Context

`SWR_IPC_0008` requires a Ring 3 COM1 TTY server driven by IRQ 4 pulses,
`<termios.h>` line discipline, blocking `stdin` `read()`, and `ppoll()`
readiness. Previously, `read(STDIN_FILENO, ...)` returned `ENOSYS` and `ppoll()`
routed only `/dev/pipe` descriptors.

## Decision

- Spawn `servers/ttyserv/main.c` (`COMP_IPC_0010`) with `CAP_SYS_INTR` at
  priority `105` (below `sysproc` `110` and above tests `100`). It verifies
  IOAPIC IRQ 4 delivery via a 1-byte 16550A loopback pulse before any test
  writes to COM1, then registers `/dev/tty`.
- Define `/dev/tty` IPC structures in `libc/include/sys/tty.h` (`ICD_IPC_0010`)
  within `IPC_MSG_MAX` (`512` bytes) and add `FD_KIND_TTY` (`5`) plus
  `PULSE_CODE_TTY_TICK` in `libc/include/sys/fd.h`.
- Implement canonical (`ICANON`, `ICRNL`, `VERASE`, `VKILL`, `VEOF`) and raw
  (`VMIN`) line discipline with deferred blocking `read`/`ppoll` queues in
  `ttyserv`.
- Add standalone `<termios.h>` (`ICD_IPC_0011`), `isatty` in `<unistd.h>`, and
  async-signal-safe wrappers in `libc/src/tty.c` (`COMP_IPC_0011`), with
  `tcdrain` checking deferred cancellation.
- Upgrade `ppoll()` in `libc/src/fd.c` to use direct single-server blocking RPC
  when polling one server type and deadline-bounded non-blocking polling when
  combining `/dev/pipe` and `/dev/tty` descriptors.

## Rejected alternatives

- Reading COM1 inside Ring 0 (violates the microkernel boundary in `ADR_0003`).
- Polling COM1 ports with busy loops instead of IOAPIC IRQ 4 pulses.

## Consequences

- Blocking `stdin` `read()`, `/dev/tty`, `<termios.h>`, `isatty`, and
  multi-server `ppoll()` are active and verified by `ttytest` (`VER_IPC_0006`)
  and all four POSIX CTest gates.
- `TSK_0018` (`sockserv`) can plug directly into the multi-server `ppoll()`
  structure.
```
