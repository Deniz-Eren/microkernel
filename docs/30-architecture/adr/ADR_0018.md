# ADR_0018 — Ring 3 Serial TTY Server, Termios, and Multi-Server ppoll

```{adr} Ring 3 serial TTY server, termios, and multi-server ppoll
:id: ADR_0018
:status: accepted

## Context

For `SWR_IPC_0008`, the system must give a Ring 3 COM1 TTY server on IRQ 4
pulses, `<termios.h>` line discipline, synchronous `stdin` `read()`, and
`ppoll()` checks. Before this decision, `read(STDIN_FILENO, ...)` gave `ENOSYS`,
and `ppoll()` operated only on `/dev/pipe` descriptors.

## Decision

- The kernel starts `servers/ttyserv/main.c` (`COMP_IPC_0010`) with
  `CAP_SYS_INTR` at priority `105` (below `sysproc` `110` and above tests
  `100`). It does a check of IOAPIC IRQ 4 with a 1-byte 16550A loopback pulse
  before tests write to COM1, and then records `/dev/tty` in `sysproc`.
- `libc/include/sys/tty.h` (`ICD_IPC_0010`) sets `/dev/tty` IPC structures in
  `IPC_MSG_MAX` (`512` bytes). `libc/include/sys/fd.h` adds `FD_KIND_TTY` (`5`)
  and `PULSE_CODE_TTY_TICK`.
- `ttyserv` gives canonical (`ICANON`, `ICRNL`, `VERASE`, `VKILL`, `VEOF`) and
  raw (`VMIN`) line discipline with deferred synchronous `read` and `ppoll`
  queues.
- The project adds standalone `<termios.h>` (`ICD_IPC_0011`), `isatty` in
  `<unistd.h>`, and async-signal-safe wrappers in `libc/src/tty.c`
  (`COMP_IPC_0011`). `tcdrain` does deferred cancellation checks.
- `ppoll()` in `libc/src/fd.c` uses one synchronous IPC call for one server type
  and time-bounded asynchronous polls when `/dev/pipe` and `/dev/tty`
  descriptors mix.

## Rejected alternatives

- COM1 port reads in Ring 0, which do not obey the microkernel boundary in
  `ADR_0003`.
- Busy loops on COM1 ports as an alternative to IOAPIC IRQ 4 pulses.

## Results

- Synchronous `stdin` `read()`, `/dev/tty`, `<termios.h>`, `isatty`, and
  multi-server `ppoll()` are active, and `ttytest` (`VER_IPC_0006`) and all four
  POSIX CTest checks do tests for them.
- `TSK_0018` (`sockserv`) can connect to the multi-server `ppoll()` layer.
```
