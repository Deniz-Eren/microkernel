# ADR_0020 — Ring 3 AF_UNIX Local Sockets Server and POSIX accept4

```{adr} Ring 3 AF_UNIX local sockets server and POSIX accept4
:id: ADR_0020
:status: accepted

## Context

For `SWR_IPC_0009`, the system must give Ring 3 `AF_UNIX` local sockets,
`<sys/socket.h>`, `<sys/un.h>`, and POSIX.1-2024 `accept4` with atomic
`SOCK_CLOEXEC` and `SOCK_NONBLOCK`. Before this decision, user executables had
only unidirectional `/dev/pipe` streams and no bidirectional local socket
endpoints.

## Decision

- The kernel starts `servers/sockserv/main.c` (`COMP_IPC_0012`) as a Ring 3
  server that records `/dev/sock` in `sysproc`. It controls up to 48 `AF_UNIX`
  `SOCK_STREAM` and `SOCK_DGRAM` sockets, 4 KiB receive buffers, accept queues,
  and deferred synchronous `accept`, `recv`, `send`, and `ppoll` queues.
- `libc/include/sys/sock.h` (`ICD_IPC_0012`) sets the `/dev/sock` IPC protocol
  in `IPC_MSG_MAX` (`512` bytes). `libc/include/sys/fd.h` adds `FD_KIND_SOCK`
  (`6`) and `PULSE_CODE_SOCK_TICK`.
- `proc_close_fds()` in `kernel/core/proc.c` sends `PULSE_CODE_FD_CLOSE` to
  `sockserv` on `O_CLOEXEC` `execve` and process exit.
- The project adds standalone `<sys/socket.h>` and `<sys/un.h>` (`ICD_IPC_0013`)
  with async-signal-safe wrappers in `libc/src/socket.c` (`COMP_IPC_0013`).
  These wrappers do deferred cancellation checks on `accept`, `accept4`,
  `connect`, `send`, `sendto`, `recv`, and `recvfrom`.
- `libc/src/fd.c` adds `FD_KIND_SOCK` dispatch for `read`, `write`, `dup`,
  `dup2`, `dup3`, `close`, `fork`, and one-server or multi-server `ppoll()`.

## Rejected alternatives

- Socket buffers in Ring 0, which do not obey the microkernel boundary in
  `ADR_0003`.
- Post-accept `fcntl()` calls for `SOCK_CLOEXEC` and `SOCK_NONBLOCK`, which do
  not keep POSIX.1-2024 atomicity across concurrent `fork` and `execve`.

## Results

- `AF_UNIX` `SOCK_STREAM` and `SOCK_DGRAM` sockets, `socketpair`, `accept4`, and
  multi-server `ppoll()` across sockets and pipes are active. `socktest`
  (`VER_IPC_0007`) and all four POSIX CTest checks do tests for them.
```
