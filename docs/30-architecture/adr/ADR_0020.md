# ADR_0020 — Ring 3 AF_UNIX Local Sockets Server and POSIX accept4

```{adr} Ring 3 AF_UNIX local sockets server and POSIX accept4
:id: ADR_0020
:status: accepted

## Context

`SWR_IPC_0009` requires Ring 3 `AF_UNIX` local sockets, `<sys/socket.h>`,
`<sys/un.h>`, and POSIX.1-2024 `accept4` with atomic `SOCK_CLOEXEC` and
`SOCK_NONBLOCK`. Previously, user programs had only unidirectional `/dev/pipe`
streams and no bidirectional local socket endpoints.

## Decision

- Spawn `servers/sockserv/main.c` (`COMP_IPC_0012`) as a Ring 3 server
  registering `/dev/sock` with `sysproc`. It manages up to 48 `AF_UNIX`
  `SOCK_STREAM` and `SOCK_DGRAM` sockets, 4 KiB receive buffers, accept queues,
  and deferred blocking `accept`/`recv`/`send`/`ppoll` queues.
- Define the `/dev/sock` IPC message protocol in `libc/include/sys/sock.h`
  (`ICD_IPC_0012`) within `IPC_MSG_MAX` (`512` bytes) and add `FD_KIND_SOCK`
  (`6`) plus `PULSE_CODE_SOCK_TICK` in `libc/include/sys/fd.h`.
- Extend `proc_close_fds()` in `kernel/core/proc.c` to deliver
  `PULSE_CODE_FD_CLOSE` to `sockserv` on `O_CLOEXEC` `execve` and process exit.
- Add standalone `<sys/socket.h>` and `<sys/un.h>` (`ICD_IPC_0013`) plus
  async-signal-safe wrappers in `libc/src/socket.c` (`COMP_IPC_0013`). They
  check deferred cancellation on `accept`, `accept4`, `connect`, `send`,
  `sendto`, `recv`, and `recvfrom`.
- Extend `libc/src/fd.c` so `read`, `write`, `dup`, `dup2`, `dup3`, `close`,
  `fork`, and single-server or multi-server `ppoll()` dispatch `FD_KIND_SOCK`.

## Rejected alternatives

- Implementing socket buffers inside Ring 0 (violates the microkernel boundary
  in `ADR_0003`).
- Emulating `SOCK_CLOEXEC` and `SOCK_NONBLOCK` with post-accept `fcntl()` calls
  (breaks POSIX.1-2024 atomicity across concurrent `fork`/`execve`).

## Consequences

- `AF_UNIX` `SOCK_STREAM` and `SOCK_DGRAM` sockets, `socketpair`, `accept4`, and
  multi-server `ppoll()` across sockets and pipes are now active. `socktest`
  (`VER_IPC_0007`) and all four POSIX CTest gates verify them.
```
