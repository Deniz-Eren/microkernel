# ADR_0021 — Ring 3 POSIX.1-2024 XCU Shell (sh) and Core Utilities

```{adr} Ring 3 POSIX.1-2024 XCU shell (sh) and core utilities
:id: ADR_0021
:status: accepted

## Context

`SWR_LIBC_0006` requires a Ring 3 POSIX.1-2024 XCU shell (`sh`) and minimal core
utilities (`echo`, `cat`, `ls`, `true`, `false`, `test`). They must support
pipelines, redirections, Issue 8 `$'...'` ANSI-C quoting, `set -o pipefail`, and
`read -d`.

## Decision

- Create a top-level `bin/` directory (`bin/CMakeLists.txt`, `COMP_LIBC_0005`)
  for standalone Ring 3 userland utilities packed into `boot.tar` and add `bin`
  to `scripts/formatter-agent.sh` and `scripts/build-agent.sh` lint scans.
- Implement `bin/sh/main.c` supporting `sh -c`, script files, and interactive
  `isatty()` input on `stdin`. Stream tokenization per pipeline so `$VAR`,
  `${VAR}`, and `$?` expand after preceding `export`, assignment, or `read`
  commands.
- Support POSIX pipelines over `pipe2(O_CLOEXEC)` and `fork`/`dup2`/`execvp`,
  negated `!` pipelines, `&&`/`||`/`;` lists, and redirections (`<`, `>`, `>>`,
  `2>`, `2>>`, `2>&1`, `>&2`).
- Support POSIX.1-2024 Issue 8 `$'...'` ANSI-C escape quoting, `set -o
  pipefail`, and byte-granular `read [-r] [-d delim]` (including `-d ''` NUL
  delimiters). Built-ins cover `cd`, `pwd`, `export`, `unset`, `set`, `read`,
  `exit`, `echo`, `true`, and `false`.
- Implement standalone utilities `bin/utils/{echo,cat,ls,true,false,test}.c`
  over standard POSIX.1-2024 `libc` headers (`<stdio.h>`, `<dirent.h>`,
  `<sys/stat.h>`, `<unistd.h>`).

## Rejected alternatives

- Placing userland utilities inside `servers/` (mixes persistent system daemons
  with transient POSIX commands).
- Tokenizing and expanding an entire script up front (breaks `$VAR` and `$?`
  updates produced by earlier commands in the same `-c` script).

## Consequences

- User programs and QEMU tests can invoke `/boot/sh` and core utilities for
  scripted or interactive POSIX command execution (`VER_LIBC_0007`).
```
