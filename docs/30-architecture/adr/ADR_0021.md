# ADR_0021 — Ring 3 Command Shell (sh) and Core Utilities for POSIX.1-2024

```{adr} Ring 3 command shell (sh) and core utilities for POSIX.1-2024
:id: ADR_0021
:status: accepted

## Context

For `SWR_LIBC_0006`, the system must give a Ring 3 command shell (`sh`) and core
utilities (`echo`, `cat`, `ls`, `true`, `false`, `test`) that target
POSIX.1-2024 XCU interfaces. They must operate with pipelines, redirections,
Issue 8 `$'...'` ANSI-C literals, `set -o pipefail`, and `read -d`.

## Decision

- The project adds a top-level `bin/` directory (`bin/CMakeLists.txt`,
  `COMP_LIBC_0005`) for standalone Ring 3 utilities packed into `boot.tar`.
  `scripts/formatter-agent.sh` and `scripts/build-agent.sh` include `bin` in
  format and static-analysis checks.
- `bin/sh/main.c` operates with `sh -c`, script files, and interactive
  `isatty()` input on `stdin`. It parses tokens for each pipeline. Thus `$VAR`,
  `${VAR}`, and `$?` expand after `export`, assignment, or `read` commands.
- The shell gives POSIX pipelines on `pipe2(O_CLOEXEC)` and
  `fork`/`dup2`/`execvp`, negated `!` pipelines, `&&`/`||`/`;` command
  sequences, and redirections (`<`, `>`, `>>`, `2>`, `2>>`, `2>&1`, `>&2`).
- The shell gives POSIX.1-2024 Issue 8 `$'...'` ANSI-C literals, `set -o
  pipefail`, and byte-level `read [-r] [-d delim]` (with `-d ''` NUL
  delimiters). Built-in commands include `cd`, `pwd`, `export`, `unset`, `set`,
  `read`, `exit`, `echo`, `true`, and `false`.
- `bin/utils/{echo,cat,ls,true,false,test}.c` gives standalone utilities on
  POSIX.1-2024 `libc` headers (`<stdio.h>`, `<dirent.h>`, `<sys/stat.h>`,
  `<unistd.h>`).

## Rejected alternatives

- User-space utilities in `servers/`, which mixes continuous system servers with
  transient POSIX commands.
- Full-script expansion before start, which breaks `$VAR` and `$?` changes from
  previous commands in the same `-c` script.

## Results

- User executables and QEMU tests can start `/boot/sh` and core utilities for
  scripted or interactive POSIX command operation (`VER_LIBC_0007`).
```
