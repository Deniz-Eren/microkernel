# ADR_0001 — Sphinx-Needs for Document Traceability

```{adr} Sphinx-Needs for document traceability
:id: ADR_0001
:status: accepted

## Context

Software specifications, architecture decisions, and verification items must
agree with source code and tests in Git without manual tables.

## Decision

The project uses Sphinx, MyST-Parser, and Sphinx-Needs from
`.docs-traceability-setup.yml`. The CMake build does automatic checks of all
traceability links, statuses, and code markers.

## Rejected alternatives

- Manual traceability tables in Markdown files or spreadsheets.
- An external proprietary tool not in Git for requirements.

## Results

- Authors write each item one time, and the build makes the views.
- The build writes output to `<build>/docs/` and stops on warnings.
```
