# ADR_0001 — Adopt Sphinx-Needs for Docs-as-Code Traceability

```{adr} Adopt Sphinx-Needs for docs-as-code traceability
:id: ADR_0001
:status: accepted

## Context

Engineering specifications, architecture decisions, and verification items must
stay synchronized with source code and tests in version control without manual
cross-reference tables.

## Decision

Use Sphinx, MyST-Parser, and Sphinx-Needs from `.docs-traceability-setup.yml`.
Validate all traceability links, statuses, tags, and code references during the
CMake build.

## Rejected alternatives

- To keep traceability matrices by hand in Markdown tables or spreadsheets.
- Storing requirements in an external proprietary tool outside Git.

## Consequences

- Authors write each item one time. The build generates the views.
- Builds remain out-of-source under `<build>/docs/` with warnings as errors.
```
