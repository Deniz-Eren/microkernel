# BDR_0003 — Target POSIX.1-2024 (Issue 8) Base Conformance

```{bdr} Target POSIX.1-2024 (Issue 8) Base conformance
:id: BDR_0003
:status: accepted
:drives: SYS_LIBC_0001

## Context

User programs and system servers need a standard C and operating system
interface rather than an ad-hoc API that blocks portability and conformance
testing.

## Decision

Align the user-space C library, public headers, error numbers, signals, threads,
and process interfaces to IEEE Std 1003.1-2024 (The Open Group Base
Specifications Issue 8, `_POSIX_VERSION=202405L`) over successive milestones.

## Rejected alternatives

- Defining a permanent custom-only C runtime API with no standard baseline.
- Targeting older POSIX Issue 6 or Issue 7 subsets instead of Issue 8.

## Consequences

- `libc` headers and functions follow Issue 8 namespace, `errno`, and
  feature-test macro rules as each subsystem matures.
- Standard POSIX conformance test suites can verify user-space behavior.
```
