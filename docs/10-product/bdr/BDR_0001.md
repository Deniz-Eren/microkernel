# BDR_0001 — Make End-to-End Traceability Links Mandatory

```{bdr} Make end-to-end traceability links mandatory
:id: BDR_0001
:status: accepted
:drives: SYS_DOCS_0001

## Context

Stakeholders must have checkable proof that each system requirement comes from
an accepted business goal and has automatic test results.

## Decision

An accepted business decision record sets each active system requirement.
Forward links connect each requirement down through software requirements,
architecture items, and verification items.

## Rejected alternatives

- Isolated spreadsheets for requirements and test coverage.
- Straight code links to top-level business goals without middle specifications.

## Results

- Sphinx-Needs calculates the coverage tables and the back-links from one model.
- Missing upstream business rationale or downstream tests stop the build.
```
