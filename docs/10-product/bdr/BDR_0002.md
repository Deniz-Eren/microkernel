# BDR_0002 — Build a Small x86-64 Microkernel with User-Space Services

```{bdr} Build a small x86-64 microkernel with user-space services
:id: BDR_0002
:status: accepted
:drives: SYS_BOOT_0001, SYS_MEM_0001, SYS_PROC_0001, SYS_IPC_0001, SYS_SIG_0001
:governs: ADR_0002

## Context

A monolithic kernel places drivers, filesystems, and service registries in Ring
0, which expands the trusted computing base and makes faults fatal to the entire
operating system.

## Decision

Keep the Ring 0 kernel minimal on x86-64: boot and platform setup, W^X memory
management, preemptive thread scheduling, synchronous IPC, and signal delivery.
Run system servers and applications in isolated Ring 3 processes.

## Rejected alternatives

- Building a monolithic kernel with in-kernel drivers and filesystems.
- Running system services in Ring 0 without address-space isolation.

## Consequences

- Kernel defects stay confined to five core subsystems.
- User-space servers communicate through kernel IPC channels and a name service.
```
