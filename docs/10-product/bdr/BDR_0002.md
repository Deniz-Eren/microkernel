# BDR_0002 — Make a Small 64-Bit Microkernel with User-Space Services

```{bdr} Make a small 64-bit microkernel with user-space services
:id: BDR_0002
:status: accepted
:drives: SYS_BOOT_0001, SYS_MEM_0001, SYS_PROC_0001, SYS_IPC_0001, SYS_SIG_0001
:governs: ADR_0002

## Context

A monolithic kernel puts drivers, filesystems, and service registries in Ring 0.
That expands the trusted code base and lets driver defects stop the system.

## Decision

Keep the Ring 0 kernel small: boot and platform initialization, W^X memory
management, preemptive thread scheduling, synchronous IPC, and signals. Operate
system servers and user executables as isolated Ring 3 processes.

## Rejected alternatives

- A monolithic kernel with in-kernel drivers and filesystems.
- System services in Ring 0 without isolated address spaces.

## Results

- Kernel defects stay isolated to five core subsystems.
- User-space servers communicate through kernel IPC channels and a name service.
```
