# WDR_0008 — Enforce All Quality Gates in build-agent and pre-commit

```{wdr} Enforce all quality gates in build-agent and pre-commit
:id: WDR_0008
:status: accepted
:governs: ARC_DOCS_0001, ADR_0001

## Context

Manual per-file runs of `ste_check.py` and ad-hoc checks allowed non-compliant
prose and stale doctrees to slip into commits. Quality verification must run
automatically across the entire repository before every commit.

## Decision

- Maintain `tools/check_ste.py` to check `README.md` and all non-immutable
  Markdown files under `docs/`, including Sphinx-Needs directive bodies.
- Make `scripts/build-agent.sh` the single mandatory pre-commit gate. It runs
  `formatter-agent.sh`, `check_text.py --root .`, `tools/check_ste.py --root .`,
  clean doctree rebuilds, 4-stage build + Sphinx `-W`, QEMU tests, `clang-tidy`,
  and full CTest (`6/6`).
- Provide `scripts/install-hooks.sh` to install `.git/hooks/pre-commit` running
  formatting, `check_text.py`, `tools/check_ste.py`, doctree reset, and CTest
  automatically on every `git commit`.

## Rejected alternatives

- Relying on manual per-file CLI commands from agent checklists.
- Checking only modified files and leaving latent drift across `docs/`.

## Consequences

- Every commit automatically enforces formatting, source text, ASD-STE100,
  build, QEMU runtime verification, `clang-tidy`, and Sphinx-Needs traceability.
- Stale Sphinx doctree pickles cannot trigger false duplicate-ID warnings when
  tasks move to `docs/records/HISTORY.md`.
```
