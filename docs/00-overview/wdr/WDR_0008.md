# WDR_0008 — Make All Quality Checks Mandatory in build-agent and pre-commit

```{wdr} Make all quality checks mandatory in build-agent and pre-commit
:id: WDR_0008
:status: accepted
:governs: ARC_DOCS_0001, ADR_0001

## Context

Manual single-file `ste_check.py` commands and subset checks let prose errors
and expired doctrees go into commits. Quality checks must operate automatically
across the full repository before each commit.

## Decision

- Keep `tools/check_ste.py` to do optional STE checks on `README.md` and
  non-immutable Markdown files in `docs/`. Include Sphinx-Needs directive bodies
  and skip without error when `ste-writing-skill` is missing.
- Make `scripts/build-agent.sh` the one mandatory pre-commit check. It does
  `formatter-agent.sh`, `check_text.py --root .`, optional `tools/check_ste.py
  --root .`, clean doctree builds, four-step build with Sphinx `-W`, QEMU tests,
  `clang-tidy`, and full CTest.
- Give `scripts/install-hooks.sh` to install `.git/hooks/pre-commit`. That
  script does format checks, `check_text.py`, optional `tools/check_ste.py`,
  doctree cleanup, and CTest automatically on each `git commit`.

## Rejected alternatives

- Manual single-file CLI commands from agent checklists.
- Checks on changed files alone, which keep hidden errors across `docs/`.

## Results

- Each commit automatically does format, source text, optional STE, build, QEMU
  runtime, `clang-tidy`, and Sphinx-Needs traceability checks.
- Expired Sphinx doctree pickles cannot cause incorrect duplicate-ID warnings
  when tasks move to `docs/records/HISTORY.md`.
```
