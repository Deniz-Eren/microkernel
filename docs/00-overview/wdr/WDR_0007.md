# WDR_0007 — Align clang-format, clang-tidy, and Source-Text Configs

```{wdr} Align clang-format, clang-tidy, and source-text configs
:id: WDR_0007
:status: accepted
:governs: ARC_DOCS_0001

## Context

Static analysis flagged intentional linker symbols (`__bss_start`,
`__text_start`) as reserved identifiers and flagged syscall out-parameters as
uninitialized. In addition, `.clang-format` initially wrapped at 100 columns
while `.editorconfig` and `check_text.py` enforced 80 columns, and verbatim
third-party specifications triggered text-check false positives.

## Decision

- Disable `bugprone-reserved-identifier` in `.clang-tidy`, export
  `build/compile_commands.json` in `scripts/env.sh`, and suppress syscall
  out-param false positives at call sites with named `NOLINT` comments or zero
  initialization.
- Set `ColumnLimit: 80` in `.clang-format` to match `.editorconfig`.
- Exempt only immutable verbatim documents (`LICENSE.md` and
  `docs/skills/*/references/*`) in `.editorconfig` and upgrade human-authored
  sources to Doxygen headers.

## Rejected alternatives

- Disabling `clang-analyzer-core.*` checks project-wide.
- Raising `.editorconfig` line limits to 100 columns for C files.

## Consequences

- `clang-format`, `clang-tidy`, `.editorconfig`, and `check_text.py --root .`
  agree on 80 columns and pass with zero findings across the repository.
- Immutable specification references remain verbatim and untouched.
```
