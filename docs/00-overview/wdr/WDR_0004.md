# WDR_0004 — Use the MIT License and Source Copyright Headers

```{wdr} Use the MIT License and source copyright headers
:id: WDR_0004
:status: accepted
:governs: ARC_DOCS_0001

## Context

The project had no license file. Contributors and distributors need clear
license terms and uniform source-file attribution.

## Decision

Add `LICENSE.md` with the MIT License and copyright line `Copyright (c) 2026
Deniz Eren <deniz.eren@outlook.com>`. Start each human-authored source file with
that copyright line and `SPDX-License-Identifier: MIT`. Keep third-party
attributions separate in `docs/THIRD-PARTY-NOTICES.md`.

## Rejected alternatives

- Using a GPL-family license (strong copyleft with heavier distribution duties).
- Using Apache-2.0 or BSD-2/3-Clause instead of MIT.

## Consequences

- Distributors keep the copyright notice and MIT license text.
- Every new source file carries the header defined in `CNV_0003`.
- LLVM freestanding headers in `sysroot/` keep their upstream license and
  attribution in `docs/THIRD-PARTY-NOTICES.md`.
```
