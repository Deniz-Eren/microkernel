# WDR_0003 — Adopt AI Agent Governance and Skill Procedures

```{wdr} Adopt AI agent governance and skill procedures
:id: WDR_0003
:status: accepted
:governs: ARC_DOCS_0001

## Context

The repository needs clear governance, state-management rules, and tool
procedures that work across all AI agent platforms without vendor lock-in.

## Decision

Apply `agent-scaffolding` (`0.2.0`) with `.agent-scaffolding.yml` and autonomous
commit mode. Place supreme agent rules in `AGENTS.md`, keep procedures in
`docs/skills/`, and symlink `.agents/skills` for discovery.

## Rejected alternatives

- Writing one-off agent instructions per platform (`CLAUDE.md` or
  `.github/copilot-instructions.md` alone).
- Copying tool procedures into multiple documents instead of linking to skills.

## Consequences

- `AGENTS.md` governs commit identity, `Assisted-by:` footers, command
  boundaries, and pre-commit verification for every agent session.
- Procedures stay in one skill file per tool or workflow under `docs/skills/`.
```
