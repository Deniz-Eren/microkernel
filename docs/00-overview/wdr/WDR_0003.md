# WDR_0003 — Use AI Agent Governance and Skill Procedures

```{wdr} Use AI agent governance and skill procedures
:id: WDR_0003
:status: accepted
:governs: ARC_DOCS_0001

## Context

The repository must have clear governance, state-management rules, and tool
procedures that operate across all AI agent platforms without vendor lock-in.

## Decision

Use `agent-scaffolding` (`0.2.0`) with `.agent-scaffolding.yml` and automatic
commit mode. Put primary agent rules in `AGENTS.md`, keep procedures in
`docs/skills/`, and symlink `.agents/skills` for discovery.

## Rejected alternatives

- Isolated agent instructions for each platform (`CLAUDE.md` or
  `.github/copilot-instructions.md` alone).
- Copies of tool procedures in more than one document as an alternative to skill
  links.

## Results

- `AGENTS.md` controls commit identity, `Assisted-by:` footers, command limits,
  and pre-commit rules for each agent session.
- Procedures stay in one skill file for each tool or workflow in `docs/skills/`.
```
