# WDR_0013 — Agent Workflow Guards and Fast-Stop QEMU Diagnostics

```{wdr} Agent workflow guards and fast-stop QEMU diagnostics
:id: WDR_0013
:status: accepted
:governs: ARC_DOCS_0001

## Context

Small local coding models spent large portions of their context window and wall
time on avoidable workflow errors during autonomous tasks. Three patterns caused
most stalls:

1. `tests/test_runner.py` waited for the full 120-second or 180-second timeout
   after a `!!! kernel exception` or `!!! system halted` line. It did not stop
   immediately with fault diagnostics.
2. `scripts/env.sh shell` ignored command arguments with exit code 0, and host
   `/tmp` paths caused raw Python tracebacks in the container mount.
3. Key build paths, `boot.tar` and VFS rules, FD startup, syscall headers, and
   virtual memory bases stayed spread across source files without one compact
   codebase map.

## Decision

- Update `tests/test_runner.py` to stop immediately on unexpected `!!! kernel
  exception`, `!!! system halted`, and `PANIC:` lines, or when all non-server
  boot tests exit with missing patterns (`--no-fail-fast` turns this off and
  `--fail-on-fail` stops on `[FAIL]`). On each error, write nonzero-exit PIDs,
  active PIDs, `[FAIL]` lines, and `llvm-addr2line` diagnostics or Ring 3 offset
  hints.
- Update `scripts/env.sh` so `env.sh shell` rejects extra arguments and `env.sh
  test` rejects host paths external to the repository. Add helper commands
  `build-code`, `test-fast`, `next-ids`, `task`, `check-text`, `check-ste`, and
  `check-fast`.
- Add `docs/00-overview/codebase-map.md` with build paths, `boot.tar` and VFS
  rules, FD startup, syscall headers, and virtual memory bases. Also include a
  Ring 3 utility and test checklist.
- Add a top-level Fast Commands and Mandatory Rules section to `AGENTS.md`.
  Mandate relative repository paths, container tool use, fast builds, STE
  limits, and a short debug procedure.

## Rejected alternatives

- Leave `test_runner.py` to time out on kernel halts, which makes agents treat
  faults as slow QEMU execution.
- Require small agents to examine `CMakeLists.txt`, `kernel/`, `libc/`, and
  `servers/` in each session as an alternative to one compact map.

## Results

- Kernel faults and halts stop in seconds with process status and
  `llvm-addr2line` diagnostics.
- Agents can examine one task (`env.sh task`), get next traceability IDs
  (`env.sh next-ids`), and do fast C and ISO builds (`env.sh build-code`) with
  low context growth.
```
