# WDR_0001 — Make Traceability Checks Mandatory in CI

```{wdr} Make traceability checks mandatory in CI
:id: WDR_0001
:status: accepted
:governs: ARC_DOCS_0001, ADR_0001

## Context

Traceability models become inaccurate quickly when checks are optional or
manual. Each change to requirements, architecture, or verification tests must
agree with the model before integration.

## Decision

The default CMake build starts Sphinx with warnings as errors. CTest does unit
tests, HTML output, JSON export, and the standalone model check.

## Rejected alternatives

- Traceability checks only before release milestones.
- Broken links or missing verification coverage as warnings that do not stop the
  build.

## Results

- Broken links, missing verification items, and incorrect code markers stop the
  build immediately.
- Authors correct content as an alternative to the removal of checks.
```
