# WDR_0001 — Enforce Traceability Gates in CI

```{wdr} Enforce traceability gates in CI
:id: WDR_0001
:status: accepted
:governs: ARC_DOCS_0001, ADR_0001

## Context

Traceability models drift rapidly when checks are advisory or manual. Every
change to requirements, architecture, or verification tests must remain
consistent before integration.

## Decision

The default CMake build runs Sphinx with warnings treated as errors, and CTest
executes unit tests, HTML generation, JSON export, and the standalone model
audit.

## Rejected alternatives

- Running traceability checks only before release milestones.
- Treating broken links or missing verification coverage as non-fatal warnings.

## Consequences

- Broken links, missing verification items, and invalid code tags stop the build
  immediately.
- Contributors correct content rather than disabling checks.
```
