# WDR_0002 — Use Two-Tier Bidirectional Code and POSIX Traceability

```{wdr} Use two-tier bidirectional code and POSIX traceability
:id: WDR_0002
:status: accepted
:governs: ARC_DOCS_0001, ADR_0003

## Context

End-to-end POSIX.1-2024 traceability must connect standard clauses to headers,
source modules, and test files. It must prevent one-for-each-function Markdown
entries across 86 headers and more than 1,100 interfaces.

## Decision

Use a two-tier bidirectional traceability method:

- **Tier 1 (Interface-level Sphinx-Needs):** Write `SWR_` requirements at the
  header, interface, or subsystem level with `ste-writing-skill` (STE). Use
  modal verb `must` (`authoring.modal_verb: must`) and a structured `:posix:`
  field. Keep `ICD_` and `COMP_` scoped to one header or option group. Tag
  public headers with `ICD_`, source modules with `COMP_`, and test files with
  `VER_`. Do not put `SYS_` or `SWR_` IDs in source code.
- **Bidirectional build check:** `need_tag_check.py` stops the build (`-W`) if
  an active `ICD_`, `COMP_`, or automatic `VER_` item has no `need::` marker. It
  also stops if a `test_*`, `*_test.*`, or `check_*` file has no `VER_` marker.
  Name new POSIX C test files `test_*.c`.
- **Source-text and language checks:** Each new or changed file must obey
  `.editorconfig` and succeed on `scripts/check_text.py` (line width, greedy
  prose layout, and Doxygen headers). It must also succeed on `clang-format`,
  `clang-tidy`, CTest, and optional `ste-writing-skill` when installed.
- **Tier 2 (Automatic manifest symbol check):** Compare symbol-level
  POSIX.1-2024 coverage against `issue8-manifest.tsv` (`SWR_DOCS_0003`). Do not
  write one directive for each small C function.

## Rejected alternatives

- Four Sphinx-Needs directives for each C library function.
- Code-to-doc checks alone, which let active `ICD_`, `COMP_`, or `VER_` items
  stay without code or tests.

## Results

- Each active interface, component, and automatic test connects to source code
  and shows in the code-to-doc and POSIX matrices.
- New POSIX functions scale cleanly without Markdown directive bloat.
```
